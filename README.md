# Sistem Informasi Mahasiswa (SIM)

Aplikasi *console-based* untuk mengelola data mahasiswa pada Program Studi Sistem Informasi.

## Identitas
- **Nama**: [Nama Lengkap Anda]
- **NIM**: [NIM Anda]
- **Kelas**: [Kelas Praktikum]

## Fitur
- Tambah data mahasiswa (NIM, Nama, Program Studi, Angkatan, IPK)
- Tampilkan seluruh data dalam format tabel (`rich`)
- Cari mahasiswa berdasarkan NIM
- Hapus data mahasiswa
- Validasi data input (panjang NIM, ketersediaan nama, rentang IPK)

## Prasyarat
- Python 3.10+
- pip
